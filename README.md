# FitFlow — Конструктор Тренувань

**FitFlow** — це сучасний вебдодаток (SPA) для планування тренувань, розроблений з дотриманням вимог семантики, доступності та продуктивності. Проєкт реалізований у рамках циклу практичних робіт з вебдизайну.

## Основні можливості
- **Каталог вправ:** Динамічне завантаження даних про вправи з зовнішнього JSON-файлу.
- **Фільтрація:** Сортування вправ за типом (Силові / Кардіо) у реальному часі без перезавантаження сторінки.
- **Мій план:** Можливість додавати вправи до персональної програми та видаляти їх.
- **Валідація профілю:** Нативна перевірка форми реєстрації (валідація email, мінімальна довжина імені) з візуальним відгуком.
- **SPA Навігація:** Плавне перемикання між розділами сайту за допомогою JavaScript.

## Технологічний стек
- **HTML5:** Повністю семантична розмітка (використано `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<fieldset>` замість несемантичних тегів).
- **CSS3:** - Використання **CSS Custom Properties** (змінних) для гнучкої стилізації.
  - Адаптивна сітка на основі **CSS Grid** та **Flexbox**.
  - Плавні анімації появи контенту (`@keyframes`) та інтерактивні стани кнопок.
- **JavaScript (ES6+):** - **Fetch API** для асинхронного завантаження даних.
  - Маніпуляції з **DOM** для динамічного рендерингу карток.
  - Реалізація логіки стану (додавання/видалення елементів масиву).

## Структура проєкту
- `index.html` — семантична структура сторінок.
- `style.css` — стилі, змінні, анімації та медіа-запити.
- `script.js` — логіка SPA, фільтрація, валідація та Fetch.
- `data.json` — база даних вправ у форматі JSON.
